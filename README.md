# RoboSoc-Tutorial-Bots
This is a repository for storing driver code for the Tutorial Robots.

If you don't have access to this repository, request access from a committee member in the discord.

To upload your code on here:
- Create a branch called your name
- Create a new folder thats labelled with your name and robot ID
  - If you do not wish to label the folder with your name that is fine, preferably name it something identifiable
  - If the code is already in an Arduino Notebook folder it should be fine to just rename that
- Upload your code into that folder
- Open a pull request against the main branch

The robot ID is a number that should be labelled on your robot board, preceded by a #.
